# Historical generated reports

These files were previously generated in the repository root by assorted test,
stress-test, and benchmark scripts. They are retained for historical reference.
They are not a current test run and are not evidence of StarCraft II game wins.
Running those scripts may regenerate ignored files at their original locations.

Current bot test evidence is generated from JUnit XML by
`scripts/update_readme_status.py`. Real-game evaluation must use
`wicked_zerg_challenger/run_mass_test.py` with its source and matchup metadata.
