existing roadmap docs (MASTER_TODO_SC2.md, INFRA_PLAN.md, MASSIVE_FIX_PLAN.md).

## Process note

Local test env requires `PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python` (the
installed protobuf's C++ backend rejects the older-generated `_pb2.py` files
in `s2clientprotocol`) — not yet pinned anywhere in CI env vars except the
two jobs touched in this PR. Worth setting repo-wide (e.g. in a `.env` /
`conftest.py` `os.environ.setdefault(...)`) so every job and every
contributor's shell picks it up without remembering the flag.
